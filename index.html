Text Contrast Benchmark

Every case the deterministic contrast solution must resolve. Each croppable target has a stable id and data-expect (PASS / FAIL / REVIEW), data-ratio (worst-pair WCAG ratio where computable), and data-note. Crop .target rects by id. Thresholds: 4.5:1 normal text, 3:1 for ≥24px. Manifest: window.TC_MANIFEST.

J — Motion backgrounds (GIF / video / CSS animation)

Text in front of something that moves. The verdict becomes a function of capture time: a single screenshot samples one frame, and the same text can pass on frame 1 and fail on frame 3. Cases split into motion-but-stable (verdict identical on every frame → confident verdict is fine) and frame-dependent (→ must defer). Append ?freeze to pause CSS animations and the video for deterministic capture (GIFs cannot be frozen by CSS — they keep playing).
